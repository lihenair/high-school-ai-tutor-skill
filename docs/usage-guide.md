# 使用指南

## 一、导入到不同平台

### Claude / Claude Code
1. 打开 Settings → Custom Instructions 或项目 system prompt
2. 粘贴 `SKILL.md` 全文
3. 对话时按模板填写年级、科目、题目

### ChatGPT
1. 打开 Custom Instructions 或创建 GPTs
2. 在 system prompt 粘贴 `SKILL.md`
3. 对话时按模板填写

### DeepSeek / Kimi / 通义
1. 创建新对话
2. 第一条消息粘贴 `SKILL.md` 全文，并写“请按以上规则辅导我”
3. 之后按模板发题

### 本地模型 / API
将 `SKILL.md` 作为 system message 传入即可。

## 二、发题模板
年级：高一
科目：数学
教材版本：人教版
当前风格：苏格拉底
题目：已知 f(x)=x²-2ax+3 在 [1,2] 上单调递增，求 a 的取值范围。
我的答案/卡点：我算出来 a≤1.5，但不确定对不对。
是否需要错题本：做完再生成


## 三、风格切换指令

- “苏格拉底” → 只引导，不给答案
- “直接讲解” → 完整解法
- “范例学习” → 先演示类似题
- “费曼技巧” → 让孩子讲，AI追问
- “脚手架” → 多提示，逐步减少
- “对比教学” → 正确vs错误解法
- “探究式” → 真实情境引入

## 四、生成错题本

1. 完整模式下自动输出错题本条目
2. 复制条目到 `错题本.xlsx`
3. 或运行 `python wrong-notebook-generator.py` 生成模板
4. 每周更新复习计划和统计看板

## 五、常见问题

**Q：AI 编造教材章节怎么办？**
A：SKILL.md 已禁止编造。若仍出现，回复“请确认章节，不确定就写对应主题”。

**Q：变式题超纲怎么办？**
A：回复“变式题禁止超纲，核心考点必须与原题一致”。

**Q：苏格拉底模式下 AI 还是给答案？**
A：回复“切回苏格拉底，只给第一个问题，不要给完整解法”。

**Q：错题本条目太长？**
A：回复“错题本只保留错因、正确思路、易错点三行”。

**Q：孩子不主动复习错题本？**
A：家长每周检查一次，让孩子口头讲一道错题，更新掌握标记。
