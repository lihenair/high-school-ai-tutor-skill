# 测试标准

## 一、内容质量测试

| 指标 | 合格标准 | 不合格信号 |
|---|---|---|
| 正确性 | 解法、答案正确；数理化先算出最终结果，并检查定义域、端点和等号。不能确定时明确写出，不给确定答案 | 算错、跳步、编造，或在不确定时仍给确定范围 |
| 教材对齐 | 章节准确或明确标注不确定 | 编造章节号 |
| 超纲标注 | 超纲方法有标注 | 把洛必达当常规 |
| 难度判断 | 用该科目自己的特征表和加权公式。默认只给基础/中等/压轴/竞赛和理由；对方要求看评分时，五项整数分乘该科目权重，两位小数 | 套用其他科目的维度，或加权与该科公式不一致 |
| 拍照识题 | 先摘题干和学生作答再辅导。关键数字看不清就问，不猜。图提供了文字里没有的条件时要写明；没有新条件时不把图当成解题条件 | 按模糊照片编造数据，把老师批改当成学生答案，或把装饰图当成条件 |
| 变式一致性 | 只锁定 1 个核心考点且保持不变；基础、进阶各 1 道，做不到时只出 1 道或说明原因。数理化生的基础变式退到直接前置，进阶变式进到直接后续；指不出时两道都停在原技能上 | 换考点或改考相邻概念还硬说变式 |
| 输出模式 | 一轮只有一种模式。引导模式不写出做法、变式和总结。完整模式或做完后的总结必须用 9 段固定标题，第 9 节附本题 mermaid 切片 | 引导时先点破突破口；做对后只回一句对错；总结里贴整章图或没有本题图谱 |
| 没学过 | 工具规则可以讲一句再练当前这一步。整题知识都没学过时，只点一个直接前置（概念、技能或实验；文科按该科规则），并让学生选补这一个或直接讲解。没有依据就写不确定 | 明知没学过仍按原子追问很多轮；一次倒出整条知识链；编造「必须先学某章」 |
| 知识图谱 | 学生问某一章的知识图谱是什么时直接出 mermaid，只展开当前章，边只用直接前置、同章衔接、常考组合。概念蓝、技能绿、实验橙、后续章节灰。做题时不把整张图谱贴出来。标明人教版化学必修第一册（2019）第一章整章图时，规定节点要齐，且不写入电石、PH₃、Cu₃P | 先反问要不要图；用纯文本箭头或默认灰图；没要图谱却整章倒出；贴题先出图；弱相关也画成边；这一章整章图缺节点或混入题目物质 |
| 卡住与跳过 | 同一小步两次答错就换提示。第三次仍错，或学生说「过」「下一个」，只公布这一小步的结果 | 原样重复上一问；或一说跳过就把整题答案给出来 |
| 直接讲解触发 | 「直接给解析」「讲一下」「给我答案」与「直接讲解」一样，进入完整模式并输出 9 段。学生说过没学过时，讲解先补那一条前置 | 学生要求解析后继续只提问 |
| 后续轮 | 同一题的难度和主题没变时，不再重报难度和主题 | 每一小步都重写一遍难度和章节 |
| 错题本 | 用户说否就不生成完整条目，没有学生答案时不写「我的错误」。要写入时进 `tutor.db`，同一题只一行。复习用未掌握、模糊、已掌握驱动 SM-2，到期题来自 `due` | 编造学生答案；同一题追加多行；仍按第 1、3、7、15 天排期；到期列表与数据库不一致 |
| 判题记录 | 一题有最终结果时用 `records.py add` 记一条，回复「已记下：科目 · 考点，结果」。问薄弱点先跑 `weak`，照脚本原文说次数。错题本另按是否需要再写 `notebook.py`，两句确认不要并成一次 | 每一小步都记；换题不记；该记的脚本没跑却写已保存；用户说否仍写入错题本；薄弱点次数与脚本不一致 |

## 二、学习效果测试（核心）

### 1. 变式题独立正确率
- 定义：不给提示，独立完成AI生成的变式题
- 合格：≥60% 且逐步上升
- 优秀：≥80%

### 2. 延迟正确率
- 定义：3天或7天后重做原题/同类题
- 合格：≥70%
- 优秀：≥85%

### 3. 错题复发率
- 定义：同类题再次错误的比例
- 合格：逐周下降
- 优秀：下降50%以上

### 4. 讲题能力
- 定义：用自己的话讲清考点、突破口、易错点
- 合格：能说出考点和大致思路
- 优秀：能指出自己上次错因并说明如何避免

### 5. 主动性
- 定义：是否主动翻错题本、主动提问、主动做变式
- 合格：每周至少主动复习1次
- 优秀：主动要求生成变式和错题本

## 三、难度匹配标准

| 学生水平 | 建议难度分布 |
|---|---|
| 基础薄弱 | 基础70% + 中等30% |
| 中等 | 基础30% + 中等50% + 压轴20% |
| 较好 | 基础10% + 中等50% + 压轴40% |
| 竞赛 | 中等30% + 压轴50% + 竞赛20% |

## 四、合格判定

2-4周内满足以下3条以上，视为有效：
1. 变式独立正确率提升
2. 错题复发率下降
3. 能讲清考点和错因
4. 延迟正确率≥70%
5. 主动复习错题本

## 五、不达标怎么办

| 问题 | 调整 |
|---|---|
| 变式还是错 | 降低难度，苏格拉底每次只多给一步提示 |
| 当时会过两天忘 | 用 SM-2 拉开复习间隔，到期再练 |
| 只会等答案 | 切回苏格拉底，禁止直接给答案 |
| 声明整题都没学过 | 停止在原题上拆基本功，只点一个直接前置，让学生选补这一个或直接讲解 |
| 同一小步反复错 | 第二次换提示；第三次只公布这一小步，进入下一步 |
| 错题本不复习 | 家长每周检查一次，标记掌握 |
| 某类错因反复 | 专项训练，集中10道同类题 |
