# 测试标准

## 一、内容质量测试

| 指标 | 合格标准 | 不合格信号 |
|---|---|---|
| 正确性 | 解法、答案正确；数理化先算出最终结果，并检查定义域、端点和等号。不能确定时明确写出，不给确定答案 | 算错、跳步、编造，或在不确定时仍给确定范围 |
| 教材对齐 | 章节准确或明确标注不确定 | 编造章节号 |
| 超纲标注 | 超纲方法有标注 | 把洛必达当常规 |
| 难度判断 | 默认只给基础/中等/压轴/竞赛和理由。若给出五项分数，每项为 1–5 的整数，加权保留两位小数且正好等于各项乘权重之和 | 等级明显不符，或加权与五项分数对不上 |
| 变式一致性 | 只锁定 1 个核心考点且保持不变；基础、进阶各 1 道，做不到时只出 1 道或说明原因 | 换考点硬说变式 |
| 输出模式 | 一轮只有一种模式。引导模式不写出做法、变式和错题本条目 | 引导时先点破突破口，或几种结构叠在一轮 |
| 错题本 | 用户说否就不生成。没有学生答案时不写「我的错误」，只写标明推测的典型易错 | 编造学生答案，或在用户拒绝后仍生成条目 |

## 二、学习效果测试（核心）

### 1. 变式题独立正确率
- 定义：不给提示，独立完成AI生成的变式题
- 合格：≥60% 且逐步上升
- 优秀：≥80%

### 2. 延迟正确率
- 定义：3天或7天后重做原题/同类题
- 合格：≥70%
- 优秀：≥85%

### 3. 错题复发率
- 定义：同类题再次错误的比例
- 合格：逐周下降
- 优秀：下降50%以上

### 4. 讲题能力
- 定义：用自己的话讲清考点、突破口、易错点
- 合格：能说出考点和大致思路
- 优秀：能指出自己上次错因并说明如何避免

### 5. 主动性
- 定义：是否主动翻错题本、主动提问、主动做变式
- 合格：每周至少主动复习1次
- 优秀：主动要求生成变式和错题本

## 三、难度匹配标准

| 学生水平 | 建议难度分布 |
|---|---|
| 基础薄弱 | 基础70% + 中等30% |
| 中等 | 基础30% + 中等50% + 压轴20% |
| 较好 | 基础10% + 中等50% + 压轴40% |
| 竞赛 | 中等30% + 压轴50% + 竞赛20% |

## 四、合格判定

2-4周内满足以下3条以上，视为有效：
1. 变式独立正确率提升
2. 错题复发率下降
3. 能讲清考点和错因
4. 延迟正确率≥70%
5. 主动复习错题本

## 五、不达标怎么办

| 问题 | 调整 |
|---|---|
| 变式还是错 | 降低难度，增加脚手架 |
| 当时会过两天忘 | 加强间隔复习，第1/3/7/15天 |
| 只会等答案 | 切回苏格拉底，禁止直接给答案 |
| 错题本不复习 | 家长每周检查一次，标记掌握 |
| 某类错因反复 | 专项训练，集中10道同类题 |
