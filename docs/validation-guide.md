# 家庭验证指南（2-4周）

## 第1周：前测 + 使用AI
1. 选一个薄弱单元，找10道同考点题做前测
2. 记录：正确率、用时、卡点
3. 每天用skill辅导1-2道典型题
4. 记录AI输出质量：难度、变式、错题本是否具体

## 第2周：延迟 + 变式
1. 3天后重做前测题，记录延迟正确率
2. 做AI生成的变式题，独立完成，不给提示
3. 让孩子口头讲一遍思路，家长听逻辑是否通顺

## 第3周：交叉对比
1. 换一个难度相近的单元，减少AI使用
2. 对比两个单元：独立正确率、错题复发
3. 注意顺序、状态、学校进度的影响

## 第4周：综合检验
1. 做一套单元测或期末模拟
2. 重点看：原来错过的同类题是否还会错
3. 翻错题本，看孩子是否主动复习、是否更新掌握标记

## 记录方式
用 `templates/validation-tracker.csv` 每周记录一次，连续2-4周看趋势。

## 好信号
- 孩子能自己说出下一步
- 会质疑AI：「这里为什么这样？」
- 变式能做对，哪怕慢
- 主动翻错题本
- 3天后重做还能对

## 坏信号
- 只等答案，看完说「懂了」
- 变式换个数就不会
- 错题本只抄不复习
- 离开AI完全没思路
- 只做喜欢的科目

## 家长注意事项
1. 验证时让孩子独立做，不要旁边提示
2. 不要用AI讲得清楚代替孩子学会
3. 难度要匹配，太难挫败、太简单无效
4. AI是辅助，不能替代动笔、复习和学校作业
5. 记录趋势比单次结果可靠

## 结论
如果2-4周内出现以下3条以上，说明skill有效：
1. 变式独立正确率提升
2. 同类错题复发率下降
3. 孩子能讲清考点和错因
4. 3天后重做仍能做对
5. 主动翻错题本、主动问问题

如果只有「AI讲得好」，孩子独立做还是错，说明skill没问题，但使用方式需要调整：减少直接看答案，增加独立做和延迟复习。
