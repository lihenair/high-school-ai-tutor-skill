# 数学机验

只在数学完整模式写出第 2 节之前读取。物理里已经抽成数值式的计算用同一套。生物里的比例、浓度、计数，抽成式子后也走这里。单位、化学方程式配平、生物概念和实验结论不机验。语文、英语、史政地的完整讲解不写机验标记。

数学完整模式在写出第 2 节之前，把最终式和条件抽出来交给 `scripts/verify.py`。只传入已经抽好的式子，不送整段回复，也不送中文大题原文。两种调用都行：

```bash
python3 <skill目录>/scripts/verify.py --expr "最终式" --where "条件"
python3 <skill目录>/scripts/verify.py --expr "2 + 2 == 4"   # 无条件时省略 --where
```

```python
from verify import check_math
check_math("最终式", "条件")
```

编号呈现的推导步骤是主链。主链上的每一步各自调一次 `check_math`。不编号的整理、合并同类项、草稿不验。把已知值代进式子可以验，也可以不验。

步骤分三类：

- 等价变形步：这一步和上一步是同一个关系的改写。直接验。`--expr` 写这一步，`--where` 写上一步；没有上一步就只验这一步本身。
- 条件等价步：只有在某个前提下才等价。前提放进 `--where`，不要当成无条件的恒等。六类条件等价和分类讨论的写法见 `references/math.md` 的「条件步清单」。
- 推理步：放缩、夹逼、构造。写明依据，不拿这一步去验等价。放缩本来就不是恒等，验等价会把对的步骤判成矛盾。

返回五种状态：通过、矛盾、超时、无法解析、未安装。命令行把状态打到 stdout，对应退出码 0、1、1、3、4（2 留给用法错误）；stdout 第一行必为状态词，有 detail 时第二行以 `detail:` 前缀另起一行。判断是否拦发送只看退出码是否等于 1，或读 stdout 第一行是否为「矛盾」或「超时」。无法解析、未安装都不拦。

**超时只有一条规则，外加一次重试/降级：**

1. 默认时限 1.5 秒。超时后立刻换新进程再算一次，第二次时限 12 秒，给多项式展开等重计算留时间。
2. 两次都超时 → 状态「超时」，退出码 1，**拦住发送**。不要把超时并进「无法解析」。
3. 拦住之后改写该步再验（拆步、去掉不必要的全展开）。只有在决定降级发出、并且不把该式当作已机验通过时，才在第 2 节写「未机验：超时」；不得写成「已机验：通过」。

小数按十进制有理数比较，所以 `1.2*3 == 3.6`、`0.1+0.2 == 0.3` 是通过，不是矛盾。无条件的错误恒等式（例如 `(a+b)**2 == a**2+b**2`）和自相矛盾的赋值（例如 `a=1; a=2`）判矛盾。链式不等式整段保留，不截成第一段。式子里的属性访问、过大的幂次记无法解析。不走 Python eval。

科学计数法按同一个精确十进制数解析：`1.6e-19`、`3.0e8`、`6.02e23`、`a×10^n`、`a*10**n`、`a·10^n`、`a×10ⁿ`（上标可带 `⁻`）。`|n| ≤ 308` 的 `10` 的整数次幂按精确十进制算；整数字面量最多 40 位。更大的幂（如 `2**4000`、`10**400`）记无法解析，不要崩、不要超时。不要把科学计数法里的 `e`/`E` 拆成自然常数。`--where` 里同样适用。

`ln`、`lg`、`log`、`sin`、`cos`、`tan`、`exp`、`sqrt` 后面不带括号、直接跟一个原子（可选数字加至多一个字母，或只有数字）时，按函数作用于该原子：`lnx` 是 `ln(x)`，`ln2` 是 `ln(2)`，`lg100` 是 `lg(100)`，`sin2x` 是 `sin(2x)`，`ln x` 是 `ln(x)`；`sinx**2` 按 `(sin x)²`。`abs`、`max`、`min`、`expand` 仍先当作函数。之后再拆 `2ab` 这种多字母乘积。以这些函数名开头却没能按函数解析的标识符（如 `lnxy`）只能得通过或无法解析，禁止因拆成字母乘积而判矛盾。

大写 `E` 始终是普通变量（场强等），与自然常数无关：`E == e` 记无法解析。小写 `e` 默认是自然常数（也可写 `exp(1)`）；若 `--where` 里给 `e` 赋了值，则按普通变量代入（元电荷等）。例外：未赋值的 `e` 只以线性方式出现（不是幂的底，也不在 `ln`/`log`/`exp` 的参数里），且式子或 `--where` 里有量级 ≤ 1e-10 的科学计数法字面量时，按自然常数会判矛盾的改为无法解析，并提示在 `--where` 写 `e = 1.6e-19`；按自然常数能通过的仍通过。没有这种量级信号的数学式（`e + 1 == 3.8`）仍按自然常数判。detail 里自然常数写 `e`（或 `exp(1)`），不要写成大写 `E`。`2ab` 按 `2*a*b` 理解。

无自由符号的纯数值等式：先做精确有理比较。两侧都是整数、分数、或不带小数点的科学计数法（如 `1e3`、`3e8`）时，只做精确比较，不容差。只要有一侧写出了带小数点的十进制（含 `1.6e-19`），或式子含 `pi` / `e` / 根式等无理量，才用「小数侧最后一位的半个单位」做容差，比较是严格小于（`delta < half-ulp`），等于半个单位也算矛盾。通过时 detail 写「数值近似」。例如 `|pi-3.14|≈0.00159 < 0.005` 通过；`|pi-3.1|≈0.0416 < 0.05` 也通过；`|1/8-0.13|=0.005` 等于 `0.13` 的半单位，记矛盾；`|sqrt(2)-1.42|≈0.0058 > 0.005` 矛盾。两侧都写出小数时取更严的半单位（所以 `9.8==9.81` 矛盾）。没有小数侧时，无理量也不容差（`pi==3` 矛盾）。`--where` 代入后用同一条规则。**容差只用于等式**；任何含小数的不等式（`<` `<=` `>` `>=`）只做精确判断，不能确定则记无法解析。因此 `pi<3.14`、`pi<=3.14`、`e<=2.718`、`sqrt(2)<=1.414`、`1/3<0.333` 都是矛盾。不另增状态词。

`π` 与 `pi` 等价。含 `pi`/`π` 的**等式**若按精确 π（加半单位容差）仍矛盾，再把 π 换成 `3.14` 重判一次（同一套半单位容差；整数结果做精确比较）。重判通过则通过，detail 写「按 π≈3.14 近似」。两种算法都不成立则矛盾（`pi == 3`、`pi*r**2 == 12.5` 且 `r=2`）。不等式仍然精确判断，不做 3.14 重判。`≈` 当作带容差的等式（`π*4 ≈ 12.56` 通过）。`--where` 里写 `pi = 3.14` 仍按赋值处理。

`--where` 里的赋值会整句代入，并按依赖链消元（`y=2; x=y+1` 先得到 `x=3`）。代入后若化简恒真则通过，恒假则矛盾。剩余自由符号默认无法解析。唯一例外：式子是 `未知数 == f(已赋值变量)`，且该未知数未在 `--where` 里赋值，且 `--where` 里至少有一个符号真正出现在原式并被代入，且右侧是实数。这只能说明未知数被公式确定，**不能**发现公式写错（例如 `E==F*q` 与 `E==F/q` 在只给 F、q 时都会通过）。未知数被代成另一个未赋值符号（`x==3` 且 `x=y`）、只给无关变量、或代入后出现 `zoo` / `nan` / 除以零（`x==1/y` 且 `y=0`），都记无法解析，不要判矛盾。

`×`、`÷`、`·`、`²`、`³`、`π`、`≈` 以及上标 `⁰-⁹`（可多位、可带 `⁻`，且必须在 NFKC **之前** 收成 `**n`）、`½`、`√` 先规范化再解析。`10**13` 和 `|n|≤308` 的 `10**n` 按精确十进制计算。无条件的 `1/0==1/0`、`oo==oo`、`log(0)==log(0)`、`0/0==0/0` 记无法解析。`--where` 若不是赋值，按等价变形的上一步做**解集比对**（等式、不等式同一套）：`--expr` 的解集与 `--where` 的解集相同则通过，少根或多根或解集不同则矛盾，解不出则无法解析。赋值链仍按上一节代入，不走解集比对。命令行里表达式以负号开头时，写成 `--expr=-1.6e-19==...`，或直接 `--expr -1.6e-19==...`（脚本会把后一种拼进 `--expr=`，避免 argparse 把负号当成新开关）。

机验标记必须由 stdout 首行背书：首行是五态词之一时，才据此写对应标记；退出码为 2 或首行不是状态词，属调用错误，改对再调，不得凭空写「已机验：通过」。

数学完整模式在第 2 节末尾写固定一句：通过时写「已机验：通过」；无法解析时写「未机验：无法解析」；超时且按上面第 3 步降级发出时写「未机验：超时」；没装 SymPy 时写「未机验：未安装 SymPy」。语文、英语、史政地的完整讲解不写这两句。苏格拉底可以在内部调用，但不要把状态说出来。

结果是矛盾时改写再查。连续两次矛盾后，写「此结果未通过机验」，不要把矛盾的式子当成正确答案发出，也不要写成已机验通过。
